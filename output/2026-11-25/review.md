### Первый — [fxceless/victory-fork](https://github.com/fxceless/victory-fork)

Форк проекта VIctory, позволяющий запускать Xbox Series игру на Windows с помощью совместимости. Включает исправления для корректного рендеринга и работы конкретного ПК.

**Кому пригодится:** Подходит для разработчиков и энтузиастов, желающих исследовать и улучшать совместимость игр Xbox Series на Windows, а также для тех, кто хочет экспериментировать с рендерингом и производительностью. (backend, devops, cli, security)

**Чем отличается от аналогов:** В отличие от оригинального VIctory, этот форк ориентирован на конкретную игру и содержит специфические патчи для улучшения рендеринга и производительности на определённом железе.

**Плюсы:**
- Высокая активность и популярность
- Чёткая лицензия GPL-3.0
- Поддержка Direct3D 12 и шейдерного компилятора
- Наличие подробного README с историей изменений

**Минусы:**
- Пока не полностью работоспособен (2.5–4 FPS)
- Ограничено одной конкретной игрой
- Отсутствуют собственные игровые файлы

### Четвёртый — [xcl-dev/xcl](https://github.com/xcl-dev/xcl)

XCL – compatibility layer, allowing Xbox Series X|S games to run natively on Windows by reimplementing console system libraries and recompiling RDNA2 shaders to DXIL.

**Кому пригодится:** Разработчикам и геймерам, которые хотят запускать собственные Xbox Series игры на ПК без эмуляции CPU, а также исследователям графических API и разработчикам игр, ориентированных на Windows. (backend, devops, cli, security, gaming, graphics)

**Чем отличается от аналогов:** В отличие от Wine/Proton, XCL не эмулирует CPU, а запускает x64 код напрямую, а также обеспечивает полную поддержку Direct3D 12 и Shader Model 6.6, а не только через эмуляцию.

**Плюсы:**
- Нативный запуск x64 кода без эмуляции CPU
- Поддержка RDNA2 шейдеров, перекомпилированных в DXIL
- Полноценная реализация системных библиотек Xbox
- Активная CI и документация

**Минусы:**
- Ограниченная поддержка игр – пока только некоторые из списка
- Требует Windows 10/11 x64 и Direct3D 12
- Документация по API может быть неполной

**Метрики:** 8181 звёзд · 1110 форков · язык Rust · лицензия GPL-2.0 · создан 2026-11-20 · последний коммит 2026-11-25

**Плюсы:**
- Нативный Rust‑приложение без браузера

- Встроенная поддержка SponsorBlock, DeArrow и Return YouTube Dislike
