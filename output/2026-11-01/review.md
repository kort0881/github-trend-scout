### Первый — [heydamir/unslop](https://github.com/heydamir/unslop)

unslop – skill for Claude Code и Codex, который преобразует «вибекодированное» UI в аккуратный, дизайнерский интерфейс, исправляя цвета, отступы и текст.

**Кому пригодится:** Подходит для дизайнеров и фронтенд‑разработчиков, которые хотят быстро улучшить внешний вид dashboards, приложений и лендингов без ручного редактирования кода. (frontend, ui-ux, devops, cli)

**Чем отличается от аналогов:** Автоматически анализирует и корректирует UI, работая с любыми фреймворками (Next.js, React, Vue, Svelte, Tailwind) и даже живыми сайтами, что редко встречается в подобных инструментах.

**Плюсы:**
- Высокая степень автоматизации редактирования UI
- Поддержка множества технологий
- Интеграция с Claude Code и Codex
- Простая установка и использование

**Минусы:**
- Ограничено только интерфейсами, не покрывает логику приложения
- Может потребовать ffmpeg для видео
- Документация фрагментарна, но достаточна

### Седьмой — [physicsdolphin/nv-uefi-unlocker](https://github.com/physicsdolphin/nv-uefi-unlocker)

UEFI pre‑driver NVIDIA GPU unlocker, written in Rust, that removes performance limits on RTX 20/30/40 series before driver loads. It works on Windows, Linux and Hackintosh via a signed bootloader and verified payload.

**Кому пригодится:** Designed for gamers, AI researchers and developers who need maximum GPU throughput on UEFI‑bootable systems without flashing VBIOS. It enables higher FP16/BF16/TF32 performance and DirectML inference on supported NVIDIA cards. (backend, devops, cli, security)

**Чем отличается от аналогов:** Unlike typical BIOS/firmware hacks, it operates entirely in UEFI pre‑boot, is fully signed, cross‑platform, and restores original state on power loss. It also provides a comprehensive compatibility matrix and automated firmware download.

**Плюсы:**
- Rust implementation ensures safety and performance
- Cross‑platform (Windows, Linux, Hackintosh)
- No VBIOS flashing required
- Verified payload with read‑back
- Extensive compatibility documentation

**Минусы:**
- Limited to RTX 20/30/40 series; older cards unsupported
- Requires UEFI and disabled Secure Boot
- Documentation mainly in Chinese, English version exists but less detailed

**Метрики:** 856 звёзд · 78 форков · язык Rust · лицензия GPL-2.0 · создан 2026-10-26 · последний коммит 2026-11-01
